# AI Response Quality Reviews

Rubric-based evaluation notes for comparing LLM responses on task completion, factual support, and instruction adherence.

**Timeline:** Freelance LLM Trainer / AI Response Evaluator — 2026

## Contents

- `rubrics/` — scoring dimensions and weights
- `samples/` — paired model outputs for comparison
- `reviews/` — evidence-based rating notes
- `validate_reviews.py` — Python checks for missing or inconsistent fields

## Run

```bash
python3 validate_reviews.py reviews/
```
